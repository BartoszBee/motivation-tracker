# 💡 Motivations App

Mała aplikacja do zapisywania i zarządzania motywacjami, zbudowana w **Next.js** i **React**.  
Umożliwia dodawanie własnych motywacji, wyświetlanie listy, usuwanie pojedynczych wpisów oraz czyszczenie całej listy. Stan aplikacji przechowywany jest w store (np. Zustand).

---

## ✨ Funkcjonalności

- Dodawanie nowej motywacji z pola tekstowego
- Wyświetlanie listy zapisanych motywacji
- Usuwanie pojedynczej motywacji
- Czyszczenie całej listy motywacji jednym kliknięciem
